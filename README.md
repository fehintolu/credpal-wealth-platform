# CredPal Wealth Platform — static homepage prototype

This is a self-contained HTML/CSS/JavaScript prototype for CredPal's proposed platform repositioning.

## Open locally

Double-click `index.html` or open it in any modern browser. No build process, package installation, or web server is required.

## Project structure

- `index.html` — page structure and content
- `assets/css/styles.css` — responsive design and animation
- `assets/js/main.js` — navigation, tabs, calculators, accordions, and scroll reveals
- `assets/images/` — local image assets used by the prototype

## Notes

- The liquidity and FX calculators are illustrative interface demos, not offers or live quotes.
- CredPal and Atom public product assets are included only for this internal concept prototype.
- The original hero image was generated specifically for this concept.
